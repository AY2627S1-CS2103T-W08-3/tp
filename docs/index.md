**ClientConnect is a desktop application that streamlines contact management for insurance agents by providing fast, CLI-optimized access to rapidly growing client lists.** It solves the inefficiency of constant data entry, enabling agents to seamlessly add, filter, and retrieve critical client details to better manage relationships and their extensive portfolios. While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* If you are interested in using ClientConnect, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing ClientConnect, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
